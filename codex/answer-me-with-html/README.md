# Answer me with HTML

[中文](README.zh-CN.md) · [Download package](answer-me-with-html.workflow-package.json) · [Comparisons](experiments/README.md)

Converted from [QingYunA/answer-me-with-html](https://github.com/QingYunA/answer-me-with-html). The original Skill defines structured Markdown, single-file HTML diagrams, narrated video, configuration, cleanup and updates. This package keeps those routes, the original runtime tools and a complete portable runtime closure. [Upstream MIT notice](UPSTREAM-LICENSE.txt) is retained, also inside the bundle.

[Upstream Skill entrypoint](https://github.com/QingYunA/answer-me-with-html/blob/main/skills/answer-me-with-html/SKILL.md) is linked for attribution; upstream `main` may advance independently of this pinned package.

Published Workflow revision: `7f1a372c03a0ce70dbd4218da10d965feed74dcd139dda7e1f8412043b46c093`. The exported package contains 34 nodes and 75 runtime resources, including the bundled 0.4.7 CLI. It excludes the private conversion source Skill and experiment answers.

Main chooses the requested route and performs semantic acceptance. Declared Host tools handle rendering, original writing checks, selected product observation and delivery. The tested page/video production paths retain their configured ephemeral Main worker execution; multiple independent pages can use the explicit batch path. This is an edited, task-specific conversion, rather than a claim that every generated Workflow uses this executor layout.

Video can reuse supplied manuscript, player HTML and completed narration. Text-only rewriting can be evaluated without speech generation. Fresh narration and MP4 export remain selectable source capabilities: the receiving host supplies the selected speech configuration and route-specific media dependencies. The package contains **no speech credentials**, and importing it does not call a speech service. Node.js 20+ is required; the workbench resolves the selected media/runtime requirements before execution.

Example requests: explain TCP with an HTML diagram; create three independent HTML explainers in one request; turn a supplied script and completed English narration into an explainer video; rewrite only the video manuscript.

Read the [experiment notes](experiments/README.md) before interpreting cost or speed. Their measured revisions precede this final publication; paid speech generation is not qualified by the final asset-reuse/text experiment.
