# GitHub README generator

[中文](github-readme-generator.zh-CN.md) · [Download Workflow](../codex/github-readme-generator/github-readme-generator.workflow-package.json)

Write, update and organize documentation for code repositories. Keep the README focused on the project's value, core capabilities and quick start, with setup and usage guides, architecture, technical references and experiment documentation where the task calls for them. Support the requested single-language or multilingual editions.

Converted from [pekral/github-readme-generator](https://github.com/pekral/github-readme-generator). The [pinned original Skill](https://github.com/pekral/github-readme-generator/blob/d8bdac94d1a9488751d65e55e78eeabd47895bd0/skills/github-readme-generator/SKILL.md), its three operational references and [license notice](../codex/github-readme-generator/UPSTREAM-LICENSE.txt) are credited and retained as applicable in the bundle.

The initiating Main chooses documentation scope and requested languages, then accepts the result. Scanning, writing/audit and translation use `native-luna`. Translation runs only when an additional language is requested. Enable this Provider and supply the target repository, scope and languages.

Choose the document structure around the readers and task: make the first successful use easy to find, place deeper material in suitable documents and connect it with clear navigation. The finished prose highlights supported advantages, uses concise project language and retains useful content and author links.

The package includes 10 nodes and 4 runtime resources and has been used to write and update the Codex Agents Workflow repository documentation in English and Chinese.
