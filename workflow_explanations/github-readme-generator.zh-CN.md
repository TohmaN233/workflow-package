个人扩展包括可选的全仓库文档整理和多语言输出。Main 按任务判断需要哪些类别；使用指南、架构、参考、实验是可选例子，并非必填四项。仅要求 README 时只处理 README。保留有用内容与作者链接，过时内容按用户要求的编辑范围处理。
