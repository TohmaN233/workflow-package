# GitHub README generator

[English](github-readme-generator.md) · [下载 Workflow](../codex/github-readme-generator/github-readme-generator.workflow-package.json)

为代码仓库编写、更新和整理文档。README 聚焦项目价值、核心能力与快速上手；按任务需要补充安装使用指南、架构、技术参考和实验说明，支持所需的单语或多语言版本。

转化自 [pekral/github-readme-generator](https://github.com/pekral/github-readme-generator)，注明[固定版本的原 Skill](https://github.com/pekral/github-readme-generator/blob/d8bdac94d1a9488751d65e55e78eeabd47895bd0/skills/github-readme-generator/SKILL.md)，保留三个操作参考及[原许可证](../codex/github-readme-generator/UPSTREAM-LICENSE.txt)。

发起任务的 Main 选择文档范围和语言，最后验收。扫描、写作／审计和翻译使用 `native-luna`；只有需要额外语言时才运行翻译。使用时启用此 Provider，并提供目标仓库、文档范围和语言要求。

文档结构按读者与任务选择：新用户容易找到第一次成功使用的路径，深入内容放在适合的文档中，并通过清晰导航串联。成稿突出有依据的优势，保持简洁、直接的项目语言，保留有用内容和作者链接。

此包包含 10 个节点、4 个运行资源，已用于编写和更新 Codex Agents Workflow 的中英文仓库文档。
